# 已知限制与发布阻塞

| 状态 | 项目 | 关闭条件 |
| --- | --- | --- |
| 已接受的兼容限制 | 当前 Mac Safari 在模型下载前丢失 WebGL 2 上下文，静态降级通过，桌面三维未通过。 | 有另一台支持 WebGL 2 的 Mac 后独立复测。 |
| 已核查的 Pages 配置 | 作者确认 Source 和 HTTPS，环境仅允许 main，候选工作流显式使用 /portal/ 和 dist-pages。既有运行在创建部署阶段返回 404。 | 首次获准部署后核对 Actions 和线上页面。 |
| 发布前需要作者授权 | 当前候选是未暂存的工作树，目标为 GitHub Pages 项目站。 | 确认 183 项公开范围、署名及素材授权；批准提交、开发分支推送与 PR。合并生产分支需要发布授权。 |
| 已知限制 | 旧基线只有首页与两个资源文件，整包回退会撤下本次新增深链。当前 Pages 工作流上传单版本，旧标签跨部署的懒载窗口取决于旧资源是否保留。 | 按部署说明记录既有线上包，决定旧资源保留或刷新提示；回退后验证旧首页及约定路径。 |
| 尚未验证 | 实际 CDN 的缓存头、公网加载速度和已部署版本，Linux 上的候选 PR 构建。 | 获准后按计划在 PR 或正式环境复验。 |
| 发布后可完善 | 更多手机型号、蜂窝弱网、长时温升和系统内存压力；补充开发笔记、个人贡献证明、可公开的联系方式和作品日期。 | 按新增证据迭代。两个实测设备、两种模型及 30/60 秒持续样本已入表。 |
