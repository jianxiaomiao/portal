# 公开范围与安全审阅

审阅覆盖候选源码、工作流、锁文件、测试、历史报告及日志、两套生产包、独立诊断包和重建的 main 回退包。检查了文本、原始字节、解析后的 glTF JSON、嵌入纹理、图片元数据、OCR 及视频画面。扫描结果以命中路径和规则类型保存，不抄录疑似秘密值。[扫描范围及结果](evidence/scan.json)

| 对象 | 结论及证据 |
| --- | --- |
| 私钥、API Key、云密钥、Access/Refresh Token、JWT、机器认证头、Cookie、数据库口令与含密码的连接串 | 常见供应商前缀、PEM、JWT、授权头、带值赋值等规则未发现真实凭证。复读三份剧情的入口、状态机和测试夹具，HTTP、Cookie、队列与 WebSocket 均以步骤标签和浏览器内状态展示。工单租约使用源码指定的示例 UUID，客服回执和读水位来自模拟消息。 |
| 聊天、作者与服务器资料 | 聊天截图和视频能对应到 scripted 客户与坐席、固定对话及重试用例。正式页使用作者给定的展示名、身份与公开 GitHub 入口。未发现真实聊天导入、电话、个人邮箱、数据库地址或生产机器登录信息。演示里的接口路径没有真实服务主机。 |
| 开发机路径 | 两份历史首次失败栈含用户目录，按文件清单私下保存。回归测试使用的回环地址与设备预览工具中的 RFC 1918 网段有测试用途。设备序列号、真实 Wi-Fi 地址、临时证书和私钥均排除在提交及产物范围之外。 |
| 静态文件与图像 | 6 张 JPEG、18 张 WebP、52 张历史 PNG 逐项解码，检查 EXIF/GPS、可识别文字及缩略图。建筑缩略图和旧海报的 EXIF 记录尺寸、分辨率、色域，未发现经纬度。两个模型各有两张内嵌 PNG，检查了贴图及 Frostwick 铭牌。7 段 WebM 各抽取 10%、50%、90% 处画面，容器显示 VP8 视频轨。101 份图像或抽帧均经过离线 OCR，90 份识别到文字。视频审核为抽样，有瞬时画面的覆盖限制。 |
| 公开运行时 | 导航 fetch 使用同源静态 HTML 路径；加载器请求版本化 layout、模型及本地解码器。可选 NewCrisp 挂件配置关闭，origin 与 siteId 均为空。生产浏览器在允许清单内发出 55 次静态请求，三章实际推进 20、19、28 步；越界 HTTP 和 WebSocket 均为 0。各异常剧情另有原套件的请求记录。[正式包请求轨迹摘要](evidence/public-network.json) |
| 生产诊断入口 | 清除了公开包中从 URL 启用逐帧阴影诊断的路径。测试对象的注册、移除及阴影参数由编译常量折叠。两份生产包均排除了探针注册符号，正式页即使指定 inspect 也没有 window.__cv。启用诊断时构建器要求独立 dist-check 输出。访客性能面板只展示当前渲染统计。 |
| 第三方与授权 | 点击仓库链接是访客主动外跳。检查未发现自动上传、遥测或向三个业务服务写入。浏览器分块内嵌的 Vue、Three.js、Meshopt 与 Vite 客户端辅助代码另附 THIRD-PARTY-NOTICES.txt，随两套正式静态包分发。公开资料依据见[内容核对](10-content.md)。素材的作者署名、授权范围仍需作者审阅。 |

文本规则、OCR 与视频抽样均有漏检可能。新增作者资料、换模型或更改挂件配置后，应对新的构建哈希重新检查。私有归档不随 Pages 发布。

## 最终白名单复核

逐项检查 183 个待提交路径，其中 RC evidence 共 32 项（29 份 JSON、3 份校验清单）。公开 JSON 已去除完整 User-Agent、GPU 驱动字符串、试验端口、临时对象 URL 标识和 ETag 原值。保留机型、浏览器版本、帧时间、缓存验证结果与相对资源路径，以便复核验收结论。原始记录保存在本机私有归档。

规则复扫及命中复读未发现真实凭证、用户目录、设备唯一标识、实测私网地址或额外个人资料。40 位十六进制命中均为公开基线 Git SHA，私网网段常量仅用于两份验收工具的地址校验。24 张运行时图像和 2 个 GLB 的字节与 Phase 10 审核版本相同，重新解析的 glTF JSON 及 extras 未见外部 URI。新构建逐文件匹配已审阅的生产清单，许可文件随包分发，私有报告和诊断包均在发布目录之外。
