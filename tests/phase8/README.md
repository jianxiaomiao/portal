# Phase 8 章节与场景回归

这些用例基于 Phase 8 原脚本，在 Portal 检测构建上操作真实浏览器和三维场景。以能提供原有诊断接口 `window.__cv` 的本地构建启动 `/explore/`，然后从 Portal 根目录执行：

```sh
CODEVILLE_URL=http://127.0.0.1:4399/explore/ node tests/phase8/suite.mjs
```

默认串行运行九项用例，避免多套测试的 GPU 采样互相干扰。可在命令末尾传入一个或多个脚本名（不含扩展名）进行复测。普通用例使用系统 Chrome 的无头模式，需要可视化时设置 `HEADLESS=0`。真实前后台切换用例会打开单独的 Chrome 窗口并创建临时用户目录；该用例运行时应让浏览器自行切换标签页。客服录屏沿用 Playwright 配套的 FFmpeg。

| 脚本 | 检查 |
| --- | --- |
| support-chat-state | 客服状态变更、重放去重、补拉时序和转派约束 |
| phase8-entry | 慢载期间的选择、三次完整重建、上下文丢失后的 RAF 与监听器回收 |
| render-contracts | 两种模型的稳定标识、街区层、静态阴影烘焙、环境动画和首载请求 |
| town-views | 四栋建筑、广场、相邻街区、六个室内热点、雪景球特写与窄屏 |
| api-request | 六组参数、HTTP/配额/用量旁路、阶段次序、重播与资源归还 |
| journey-branches | 五条工单分支、租约、回执、并发控制权、工单与账本 |
| support-chat-lifecycle | 三章互斥、十轮切换、双模型锚点、暂停与可视区域、后台资源 |
| support-chat | 四条客服剧情与三章连续切换，逐步校验消息、去重、转派与阅读水位，实际录像解码抽帧 |
| visibility | 原生标签页切走约 1.5 秒时检查环境和章节时钟，回到前台后继续 |

适配项包括测试地址、报告位置、源码路径、压缩模型计数、跨目录静态资源的同源检查，以及上下文恢复后先验证原章节配置、再回到总览对照 GPU 计数。场景状态断言取自基线。每个脚本写入 `reports/phase8/`；套件另存运行退出码、耗时和标准输出。项目通过所需的全部条件以各脚本退出码为准。
